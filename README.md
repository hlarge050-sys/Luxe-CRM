# Luxe CRM

Internal CRM for Luxe Landscaping Limited. Next.js + Drizzle + Neon Postgres,
hosted on Vercel. Single user.

## Environment variables

See `.env.example`: `DATABASE_URL` (injected by the Neon integration on
Vercel), `AUTH_PASSWORD`, `AUTH_SECRET`.

## Development

```
npm install
npm run dev
```

Build rules and milestone plan: see `CLAUDE.md`.
